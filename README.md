# Game-likeJam10
Simple 2D minecraft clone made for the Game-like Jam 10 on Itch.io

Overall, this project went way smoother than our last. We had an extra 2 weeks to work on it, which helped. But we also changed our team structure, with more active collaboration which made the process more fun and much easier. We are pretty satisfied with the experience we gained and what we were able to produce.

If you would like to play it: https://griffinrio.itch.io/dinkystinkyandthebigworm
